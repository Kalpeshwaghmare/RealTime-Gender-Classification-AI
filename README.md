# Gender Classification AI (Real-Time)

A deep learning based web application that detects **gender from live camera feed** using **TensorFlow, OpenCV and Flask**.

## Features

- Real-time gender detection
- Webcam streaming
- Deep learning CNN model
- Face detection using Haar Cascade
- Flask web interface

## Tech Stack

- Python
- TensorFlow / Keras
- OpenCV
- Flask
- HTML / CSS / JS
